# 技术落地

栈与现有引擎对齐：Python 3.11 + FastAPI + SQLite + Vue3。单独一个小项目，不要塞进 `mental_health_assessment_api`。

建议目录（电脑本机，例如 `D:\document\code\photo_lib`）：

```
photo_lib/
  apps/api/          FastAPI：导入、检索、打标
  apps/web/          Vue3 查看器
  apps/worker/       扫描 + CLIP 批处理（可和 api 同进程起步）
  packages/tags.yaml 受控词表
  data/
    library.db
    thumbs/          长边 256/512 jpg
    inbox/           你往这丢新图（或 junction 到备份盘）
  scripts/
    adb_pull.ps1     Android 一键拉取
    run.ps1          起 API + 打开浏览器
```

原图：**默认不复制**。库表只存绝对路径 + mtime + hash。你也可以选「导入时复制进 library/」，适合U 盘备份盘。

## 1. 数据表（够卖，不过度）

```
photos
  id, path, file_hash, phash, bytes, width, height,
  taken_at, imported_at, camera, gps_lat, gps_lon, source_dir,
  thumb_path, status  -- pending / ready / failed

tags
  id, name, group_name, kind  -- system / vocab / free

photo_tags
  photo_id, tag_id, source  -- exif / clip / vlm / manual
  confidence, rejected      -- 人手驳回保留痕迹

feedback
  photo_id, tag_id, action, created_at

jobs
  id, type, status, total, done, error
```

检索：`photo_tags` 上 `(tag_id, photo_id)` 索引。AND 筛就是多次 JOIN / `GROUP BY HAVING COUNT`。1～3 万张 SQLite 完全够；过 20 万再迁 PostgreSQL，第一期不要上重库。

## 2. 导入管线

1. 扫目录，跳过已有 `file_hash`
2. HEIC 用 `pillow-heif` 转解码（iPhone 刚需，不做这步软件是废的）
3. 算 sha256 + pHash（去重）
4. EXIF：拍摄时间、机型、GPS；没有拍摄时间用文件时间，并打 `时间可能不准`
5. 规则标：路径含 `Screenshot`/`WeiXin`/`Camera` 等
6. 出 256px 缩略图（网格只吃这个）
7. 入队 CLIP；API 立刻返回「已入库、打标中」

并发：按 CPU/GPU 限 worker。绿盾环境读图、比哈希用 **node 或受信 python**，不要用 PowerShell `Get-FileHash` 当下结论。

## 3. 打标模型

**主路径：本地零样本 CLIP**

- 中文相册优先 `OFA-Sys/chinese-clip-vit-base-patch16`（或 OpenCLIP ViT-B/32 + 中文提示）
- 词表 80 条，一张图一次前向图像 + 词表文本可缓存
- GPU 有则用；CPU 也能跑，1 万张可接受过夜
- 权重放本地目录，离线包交付

**辅路径：Qwen-VL（可选）**

- 只处理：CLIP 最高分 < 0.22，或用户点「这张细看」
- prompt 锁定词表，输出 JSON 数组
- 证件/发票组默认跳过
- 复用已有 `DASHSCOPE_API_KEY`

**不选的路**

- 一上来微调分类器：没标签，过拟合，像 demo
- 纯百度/腾讯看图 API：隐私 + 长期按张付费，个人库和学校档案都讲不过去
- 只靠文件名：微信导出经常是 `mmexport时间戳.jpg`，没有信息

## 4. API（查看器只打这些）

| 方法 | 路径 | 作用 |
|---|---|---|
| POST | `/v1/import` | 扫目录或收件箱 |
| GET | `/v1/photos` | 筛选：tags、op=and/or、from/to、smart=inbox\|review\|dup |
| GET | `/v1/photos/{id}` | 大图信息 + 标签 + 相近重复 |
| PUT | `/v1/photos/{id}/tags` | 人手增删 |
| GET | `/v1/tags` | 词表 + 每标数量 |
| GET | `/v1/thumbs/{id}` | 缩略图 |
| GET | `/v1/files/{id}` | 原图（本机，不给外网） |
| POST | `/v1/export` | 当前筛选复制到目标文件夹 |

本机绑定 `127.0.0.1`。以后要做「家里 NAS 给平板看」再加 token，第一期不要监听 `0.0.0.0`。

## 5. 查看器（这就是「生成一个软件来看」）

不要先做安装包。`run.ps1` 起服务并打开浏览器，任务栏一个快捷方式，对个人已经是软件。

界面（一屏能用）：

- 左：标签树 + 智能相册 + 搜索框
- 中：虚拟滚动网格（只渲染可见缩略图，1 万张也不能卡）
- 右 / 灯箱底：当前图标签、置信度、拍摄时间、路径、「不对」一键叉掉
- 多选：批量打标、批量导出、批量标待删

快捷键：`1–9` 常用标、`A` 通过待确认、`U` 取消标、`←/→` 下一张。清相册靠这个，不靠鼠标。

技术：Vue3 + TS，无路由也行（一个 App 三态：库 / 待确认 / 灯箱）。虚拟列表自己写或 `vue-virtual-scroller`。图用 `<img src=/v1/thumbs/…>`。

第二期再 Electron 包一层，如果要卖给不认浏览器的客户。内核不变。

## 6. 手机导入脚本

**Android**（有调试模式）：

```
adb pull /sdcard/DCIM/Camera   D:\PhotoLib\inbox\Camera
adb pull /sdcard/Pictures      D:\PhotoLib\inbox\Pictures
```

拉完调 `POST /v1/import`。按 hash 增量，重复拉不会翻倍。

**iPhone**：Windows 上「Apple 设备 / 爱思 / 互传」导出到 `inbox\iPhone`。HEIC 必须通。

不在第一期做「监听手机 MTP 盘符」——MTP 不稳定，售后会炸。

## 7. 测试（做成软件就要过）

- 空目录、坏图、0 字节、伪装后缀
- 同一张 jpg 拷两份：只显示一张，智能相册「重复」能找到
- HEIC 能出缩略图
- 词表改 yaml 后重跑只更新 auto，不动 manual
- 筛选 AND/OR 单测（对库插入固定 fixture，不依赖模型）
- 绿盾机器：用 node/python 读缩略图头，确认不是 `%TSD-Header`

## 8. 工期（一个人，按能用不是按完美）

| 段 | 天数 | 交付 |
|---|---|---|
| 库 + 导入 + 缩略图 + EXIF | 2 | 命令行走完 100 张 |
| CLIP 词表打标 | 2 | 自动标能看 |
| 查看器网格 + 筛选 + 改标 | 3 | 当软件用 |
| 待确认、去重、导出、adb 脚本 | 2 | 清完一批真手机备份 |
| 难例 VLM、反馈记阈值 | 2 | 专业版功能 |

约 9–11 个工作日有可自用的 1.0。再打安装包和多库是另一周。
