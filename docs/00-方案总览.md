# 手机相册识图分类 · 方案总览

> 日期：2026-08-18  
> 目标：把手机里一大堆图，变成「自动打标 + 按标签筛选」的本地图库。先给自己用稳，结构和数据能直接长成可卖的本地素材/档案产品。  
> 详细：[标签体系](01-标签体系与筛选.md) · [技术落地](02-技术落地.md) · [交付与报价](03-交付形态与商用.md)

## 1. 要做成什么样

打开软件，不是再翻文件夹，而是：

- 左边标签树（人物 / 场景 / 物品 / 时间 / 我标的）
- 中间缩略图，点选多个标签立刻收窄
- 点开大图能改标签、标错的一键纠正
- 新图丢进收件箱，后台自动打标，低把握的进「待确认」

不做成：再训练一个分类模型、不做手机端 App 第一版、不上云、不依赖必须联网。

**已拍板：只做电脑端。** 代码在 `D:\document\code\photo_lib`。本机没有可用 Python，第一期用 Node 22 自带 SQLite + Vue 查看器先把「导入 / 筛选 / 改标」卖成能用的软件；CLIP 内容标作为第二期工人挂上。

## 2. 为什么不在手机上直接跑

| 路径 | 结论 |
|---|---|
| iOS 上跑脚本 | 没越狱做不了，上架要企业签，不值 |
| Android 上跑模型 | 能做，但机型碎、耗电、难维护 |
| **电脑吃备份目录** | 一张卡/一个硬盘就能日处理几千张，还能卖给工作室 |

手机只当拍摄器。图用数据线、互传、爱思助手或系统「传输文件」拷到电脑一个固定目录。软件盯这个目录增量入库。这是 Google 相册 / Immich 都在走的形态，能卖、能维护。

## 3. 产品原则（按可卖的软件写，不是一次性脚本）

1. **图不搬家当唯一真相**：原图仍在你指定的库目录，软件只建索引和缩略图。删库软件，图还在。
2. **自动标只是建议**：每张图 = 系统标（EXIF/时间）+ 模型标（带置信度）+ 人手标（最高优先）。人手一改，以后同类可学习。
3. **标签受控，不是模型瞎吐词**：先用固定词表零样本打标，才能筛得动。自由词只给人补，不给模型随便发明 300 个近义词。
4. **能离线**：主路径 CLIP 本地推理。百炼 Qwen-VL 只当「难例加料」，没 key 照样能用。
5. **先个人库，预留多库**：桌面版一个库；以后给学校档案室/设计工作室就是多个库 + 授权。

## 4. 功能范围

### 第一期（能自己清掉手机备份）

- 指定库目录，扫描 jpg/jpeg/png/webp/heic/gif
- 去重（感知哈希 + 文件哈希）
- 读拍摄时间、机型、GPS（有就有）
- 自动打词表标签 + 人手改
- 按标签 AND/OR、按年/月、按「未标 / 低置信 / 重复」筛
- 网格浏览、灯箱、快捷键打标
- 导出：按当前筛选复制/软链到文件夹（交给别人、发朋友圈精选）

### 明确第一期不做

- 人脸自动实名（只做人脸簇「人脸 A/B」，你自己命名）——涉及隐私，默认关
- 云同步、多端实时
- 视频逐帧（视频只当附件，后期再做）
- 在手机里装一个完整图库 App

## 5. 使用流程

```
手机 DCIM / 相册导出
        │  USB / 互传 / 爱思
        ▼
电脑库目录  e.g. D:\PhotoLib\inbox
        │  监视或点「导入」
        ▼
入库脚本：hash → 缩略图 → EXIF → CLIP 打标
        │
        ▼
SQLite 索引
        │
        ▼
本机打开查看器  http://127.0.0.1:47910
        │  纠正标签、收藏、导出
        ▼
（可选）纠正结果反哺词表权重
```

Android 另附一条 `adb pull` 脚本：插上手机一键拉 `DCIM/Camera` 和 `Pictures`。iPhone 走系统导入或爱思，不折腾 ADB。

## 6. 和现有技术怎么复用

你们已经有 FastAPI + Vue3 + SQLite + 阿里百炼 Qwen-VL。这套直接复用，**不要新开一套 Electron 技术栈当第一枪**。

| 能力 | 复用 | 新写 |
|---|---|---|
| HTTP / 契约 | FastAPI + Pydantic | 图库 API |
| 界面 | Vue3 + 自写 CSS | 网格、标签树、灯箱 |
| 库 | SQLite WAL（fusion 同款） | photos / tags / photo_tags |
| 难例看懂图 | dashscope Qwen-VL | 只打 5～8 个词表内标签，禁自由发挥 |
| 主打标 | — | 本地 Chinese-CLIP 或 OpenCLIP，零样本对齐词表 |

主打标必须本地。手机几千上万张，全走百炼会慢、会漏隐私、按张计费，个人用得起但产品讲不出去「本地私有」。

## 7. 成功标准（自己用也算验收）

- 1 万张图，冷启动一夜能进完库（有核显/独显更快）
- 打开查看器 2 秒内出首页网格（只吃缩略图）
- 点 2～3 个标签，筛选结果可解释（每张能看到「为什么是这个标」）
- 纠错 50 张后，同场景再导入，明显少改

做不到这四条，就还是 demo，不要包装成软件。
