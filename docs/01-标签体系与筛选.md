# 标签体系与筛选

没有受控词表，模型会给「户外 / 外面 / 室外 / 天空」四个近义标，筛选会废。词表是产品，模型只是打分器。

## 1. 三类标签

| 类型 | 谁写 | 能不能删 | 例子 |
|---|---|---|---|
| `system` | EXIF / 文件规则 | 不给用户删，可隐藏 | `2024` `2024-08` `iPhone15` `截图` `微信导出` |
| `auto` | CLIP / 可选 VLM | 可驳回 | `猫` `菜` `发票` `证件` `夜景` |
| `manual` | 你 | 完全你说了算 | `装修前` `给爸` `可发朋友圈` |

同一张图三类可以并存。展示时：人手 > 系统 > 自动。自动标带 0–1 置信度，低于阈值进「待确认」，不进默认筛选项（避免噪声）。

## 2. 第一期词表（约 80 个，够筛手机相册）

按**你能想起来要点哪个**来分组，不按学术分类。

**来源 / 形式（规则就能打，不耗模型）**

- 截图、微信、证件扫描、表情包、实况/Live、全景、连拍

**人**

- 自拍、合影、小孩、老人、人群、手部特写  
- 人脸簇命名后挂到这类（默认关，你打开才算）

**场景**

- 家、办公室、教室、医院、店、马路、地铁、风景、夜景、室内、室外

**活动**

- 吃饭、旅行、开会、运动、演出、婚礼、考试/证件照

**物品**

- 猫、狗、花、菜、文件/白板、屏幕、车、花、商品、包装

**文档类（高频刚需）**

- 身份证/证件、发票、行程码/截图凭证、笔记、名片  
  （这类建议默认**不上传云端 VLM**，只走本地 CLIP + 人手）

**审美 / 用途（人手为主，模型只建议）**

- 可发、待删、模糊、重复、壁纸、备份即可

词表做成 `tags.yaml`，改文件即可加词，不必改模型。每个词带：中文名、英文 CLIP 提示、互斥组（如室内/室外）、默认阈值。

## 3. 模型怎么贴到词表上

对每张图算一个向量，对每个词的提示句算向量，余弦相似度 → 分数。

- 每组（场景、物品…）取 Top-N，且分数 > 阈值才落库
- 互斥组只留最高分一个（室内/室外不要同时亮）
- `截图` 用规则优先：很小、比例奇怪、来自 Screenshots 目录、几乎无 EXIF

提示句要写成「一张……的照片」，不要只写单词，中文 CLIP 才稳。例如：`一张在家里拍的室内照片`，不是 `家`。

难例（所有词都低分、或文档类你标了「值得花 API」）再可选走 Qwen-VL，**只许从词表里勾**，输出 JSON 标签列表，禁词扫描后入库。证件/发票默认不送。

## 4. 筛选怎么做才像软件

默认 **AND**：点了 `猫` + `家` = 家里的猫。  
工具栏可切 **OR**（找「猫或狗」）。  
永远能叠加：时间范围、来源目录、仅人手标、仅待确认。

固定智能相册（系统查询，不是标签）：

| 相册 | 规则 |
|---|---|
| 收件箱 | 24 小时内入库 |
| 待确认 | 有 auto 且最高分 < 阈值，或无人手标 |
| 重复 | 同一感知哈希 > 1 |
| 可能证件 | 词表命中证件/发票 |
| 未分类 | 没有任何 auto/manual |

这五个比再做一个「AI 随便分类」有用。

## 5. 人手纠正怎么变成资产

每次你删掉一个 auto 标、或加上一个 manual 标，记一条 `feedback`：

- photo_id、tag、action=add/remove、时间

第一期只用来：该图以人手为准，并给这个词微调阈值（这个词老被驳回就提高阈值）。  
第二期才考虑用这些对抽一小套线性分类头。没有反馈数据时不要训练。

## 6. 和手机文件夹的关系

手机原有相册名（微信、Camera、Screenshots）变成 **来源标签**，不覆盖内容标签。  
用户最烦的是「微信里的证件」和「相机里的猫」混在一起——来源 + 内容两个轴同时筛，才能清。
