方案 · 仅电脑端

手机里的图，在电脑上按标签找

打开可运行原型（能跳转、能弹系统选文件框，不接真实分类）

产品不是「再写一个分类脚本」，是一台电脑上的本地图库软件：拷进来、自动建议标签、人手纠正、按标签筛、按筛选导出。先给自己清相册，同一套内核以后卖给工作室和学校档案室。

1. 为何只做电脑端

手机负责拍，电脑负责管。这是 Google 相册 / Immich / Eagle 能卖的形态，也是能维护的形态。

不选 iPhone 上跑脚本 没越狱做不了。上架要证书和审核，个人相册工具不值这个成本。
不选 安卓上跑模型 机型碎、耗电、升级痛苦。几万张图在手机上过夜推理，售后会炸。
拍板 电脑吃备份目录 USB / 互传 / 爱思导出到一个文件夹。电脑日处理几千张，还能装进工作室的那台机器。
商业含义：交付物是「装在 Windows 上的本地软件」，不是「请在手机里开调试模式跑命令」。采购方听得懂，也过得了数据不出域。

2. 使用流程

人只做两件事：把图拷过来，纠正明显错的标。其余后台做。

01 手机导出 线缆 / 互传 / 爱思，拷到电脑某个盘
→
02 指定目录导入 扫描增量，hash 去重，原图不动
→
03 自动建议标签 时间 / 来源规则 + 本地 CLIP 词表
→
04 查看器筛选 点标签收窄，灯箱里改标
→
05 导出精选 当前筛选复制到文件夹，交给别人
角色干什么不干什么
你拷目录、看「待确认」、叉掉错标、导出不给每张图从零打标
软件索引、缩略图、规则标、内容建议、筛选不删手机原图、不默认上传云

3. 图片导入（电脑怎么把图吃进来）

导入方式必须多样，但默认只要一下：点「导入」→ 弹出系统资源管理器 → 选文件夹或一批文件。不要让人先填路径。后面的管道（哈希 / EXIF / 缩略图 / 入队）都一样。

默认 · 最简单 点按钮，弹出资源管理器 「导入文件夹」走系统选目录对话框（Windows 文件夹选取器）。「导入图片」多选 jpg/png/heic… 选完立刻入队。这是桌面软件该有的第一入口，路径框只做高级项。
同样常用 拖进窗口 把文件夹或一批图拖到网格空白处松开，等同选中。资源管理器里多选拖过来也算。
懒人 盯死 inbox 手机互传/爱思固定拷到 data/inbox，软件启动或点「扫描收件箱」自动吃增量。适合每周清一次手机。

4. 模型内容（谁给图打内容标签）

三层，不是一个黑盒。规则不要模型；主内容标必须本地；云端只打难例，可关。

层模型 / 算法输入输出（写入库）何时跑
L0 规则 路径 + EXIF，无模型 文件路径、拍摄时间、机型 系统标：微信 / 截图 / 相机 / 2024 / 2024-08 导入当时，必跑
L1 主模型 中文 CLIP 零样本
首选 OFA-Sys/chinese-clip-vit-base-patch16		 缩略图或压过的原图 + 词表 80 条提示句 词表内自动标 + 0～1 置信度 + source=clip 导入进队列后，点主界面「启动分类」开跑。设置可开「导入后自动开始」。GPU 更好，CPU 可过夜
L2 辅模型 Qwen-VL（百炼，可选） 难例图（CLIP 最高分 < 0.22，或人点「细看」） 只许从词表勾选的标签 JSON，source=vlm 默认关。证件/发票组永不送
CLIP 怎么贴到词表 一张图一个向量，对 80 个提示句打分 提示写成「一张在家里拍的室内照片」，不要只写「家」。每组取 Top-N 且过阈值才落库。室内/室外互斥，只留最高分。
权重放哪 本地目录，离线包交付 约 400MB 级。装软件时拷到 models/clip。没网也能打标。这是个人版和内网版都能卖的前提。
明确不选 三种看起来快、卖不出去的路 ① 上来微调分类器（没标签会过拟合）② 百度/腾讯看图按张付费（隐私 + 账单）③ 只靠文件名（微信全是 mmexport 时间戳）
模型不改像素。它只往 photo_tags 写建议。文件从 inbox 移/复制进正库后，正库那份就是资产原件，之后只追加标签，不再重写图片。

5. 数据保存（图、库、标分别落在哪）

图库有一个固定根目录（安装时选定，可改）。处理完成的图必须进这个根下的 library/，不能继续停在桌面、微信导出夹或 inbox。

正库 · 图的家 {库根}/library/年/月/ 模型处理完成后，正式原图落在这里。文件名 20260818_a1b2c3d4e5f6_原名.jpg。网格、导出、备份都只认这里。
中转 · 不是家 {库根}/inbox/ _incoming 刚选进来；_failed 坏图。成功入正库后 incoming 里那份删掉或移走，避免两份真相。
索引 + 缩略图 library.db 与 thumbs/ path 指向正库文件。缩略图按 id。模型权重在 models/。备份这四样就能搬家。

表存什么不存什么
photos path（正库绝对路径）、file_hash、phash、宽高、bytes、taken_at、imported_at、camera、GPS、source_dir、thumb_path、status 不存原图像素、不存 CLIP 768 维向量（第一期）
tags 词表名、分组、kind=system/vocab/free 不按模型自由生成新词（人手 free 除外）

feedback 人手 add/remove 的时间线 不当训练样本对外上传
jobs 导入/打标批次：total、done、error 不把失败图内容写进日志
备份 / 搬家 拷整个库根即可 拷 library/ + thumbs/ + library.db + models/。换电脑改库根路径。ready 的图都在 library 里，不再依赖当初从哪导入。
删除权 / 隐私 从库删除 = 正库文件 + 索引 + 缩略图 用户从「已有相册文件夹」导入时，外面那份备份默认不动。inbox 中转成功后不留第二份。本机只绑 127.0.0.1。
卖点：处理完的图有固定地址——都在你这台电脑的库根 library/年/月/。标签在本地库，模型在本地目录。没有「照片上传到我们的服务器」。

7. 标签：受控词表，才能筛得动

模型不许自由发明「户外 / 外面 / 室外」三个近义词。词表是产品，模型只是打分器。

类型谁写例子
系统EXIF / 路径规则2024、2024-08、微信、截图、iPhone
自动本地 CLIP 对词表打分猫、家、夜景、发票（带置信度）
人手你在灯箱里改可发、待删、装修前、给爸
证件 / 发票默认不送云端大模型。低置信进「待确认」，不进默认筛选项，避免噪声污染。

第一期词表大约 80 个：来源、人、场景、活动、物品、文档、用途。改 tags.json 即可加词，不必改模型。

8. 技术怎么铺（电脑本机）

单独项目，不塞进心理健康引擎仓。主路径离线。云端 VLM 只打难例，可关。

层选型为什么
查看器本机网页窗口（Vue）先能用；以后要卖再套安装包
服务本机 HTTP，只绑 127.0.0.1图不对外网暴露
索引SQLite1～3 万张够用，零运维
缩略图 / EXIF本地解码网格不能读原图
内容标本地 CLIP 零样本万张不按张付费
难例（可选）Qwen-VL，只许勾词表证件类默认跳过
数据原则 原图是真相，库只是索引 表里存绝对路径 + hash + 缩略图路径。删软件，图还在盘上。可选「导入时复制进库目录」，给 U 盘备份用。 纠正记录进 feedback。第一期只调阈值，有数据了再训小分类头。没反馈就不要训练。

9. 范围：能卖的第一期 vs 明确不做

第一期要交得出手

做指定目录导入，jpg/png/webp/gif，HEIC 要通（iPhone）
